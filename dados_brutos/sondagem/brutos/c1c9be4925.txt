                        <div class="row mt-2">

                            <div class="col-md-12 s-font-1">
                                <p><meta charset="utf-8"></p><p>Agenor Gomes de Araújo Neto nasceu na cidade de Iguatu, em 17 de fevereiro de 1966. É filho do médico e político, José Ilo Alves Dantas e Gláucia Mendonça Araújo Alves. É casado com Hercília Gomes Araújo, com quem teve três filhos: José Ilo Neto, Agenor Araújo Filho e Víctor Araújo Alves.</p><p>Agenor Neto fez os primeiros estudos em sua terra natal, concluindo o curso superior na Capital do Estado onde cursou a Universidade de Fortaleza – UNIFOR, vindo a graduar-se em engenharia civil, em 1989, passando de início, a trabalhar ao lado do pai, tornando-se logo um empresário competente na área da construção civil.<br>Iniciou a carreira política em 1992, candidatando-se ao cargo de prefeito de Iguatu. Em 2000, já com a vida empresarial definida, e, conhecendo detalhadamente os problemas de Iguatu, disputou novamente a Prefeitura de Iguatu pelo Partido da Social Democracia Brasileira (PSDB). As suas ideias aos poucos foram sendo assimiladas pela população, faltando pouco para atingir o seu objetivo. Conseguiu ao final da sua campanha um percentual de 47% dos votos válidos.</p><p>No ano de 2002, candidatou-se ao cargo de deputado estadual, sendo eleito com 43.826 votos.</p><p>Em 2004, afastou-se da Assembleia Legislativa para concorrer novamente ao cargo de prefeito de Iguatu, sendo eleito com a maior votação da história política do município, obtendo 25.526 votos. Em 2008 disputou a reeleição, e foi reconduzido ao cargo, derrotando a sua principal adversária com uma maioria de mais de 12 mil votos.<br>Em oito anos de mandato, Agenor Neto instaurou profundas mudanças no município de Iguatu. Construiu inúmeras obras, dando prioridade sempre aos mais necessitados. No setor da saúde, construiu e reformou unidades básicas de saúde, ampliou e melhorou o sistema de Atenção Básica na zona urbana e rural do município. Em 2010, a sua administração alcançou um dois maiores feitos na área da saúde: a diminuição na taxa da mortalidade infantil para 8,6 por mil nascidos vivos.</p><p>Agenor Neto criou programas no âmbito da Assistência Social, como o Agente do Bem e o Natal de Luz, com a distribuição de brinquedos para todas as crianças do município na faixa de idade de 0 a 12 anos. Na Educação, estruturou a rede educacional e criou o Programa Agente da Educação, programa de reforço escolar reconhecido pela UNESCO.</p><p>A eficiência da sua gestão lhe rendeu reconhecimento internacional; dois Selos UNICEF e o prêmio Prefeito Amigo da Criança. Também recebeu várias honrarias no âmbito nacional. Ao entregar o mandato ao seu sucessor, em 31 de dezembro de 2012, gozava de uma imensa aprovação popular, com 92% de aprovação, índice constatado pelo Instituto Brasileiro de Opinião Pública e Estatística – IBOPE.</p><p>Em 2014, percebendo, mais uma vez a sua imensa responsabilidade com a defesa dos direitos das pessoas mais necessitadas, resolveu candidatar-se novamente a uma vaga no legislativo estadual, obtendo uma votação expressiva de 78.868 mil votos, ficando na sétima posição entre os 46 deputados eleitos no Ceará.</p><p             function relativeLuminance(r, g, b) { return 0.2126 * srgbToLinear(r) + 0.7152 * srgbToLinear(g) + 0.0722 * srgbToLinear(b); }
            function contrastWithWhite(r, g, b) { return 1.05 / (relativeLuminance(r, g, b) + 0.05); }
            document.querySelectorAll('.col-md-5 [style*="color"], .col-md-12 [style*="color"]').forEach(function (el) {

                if (!colorMatch) return;
                var color = colorMatch[1].trim();
                var rgb = color.match(/rgb\((\d+),\s*(\d+),\s*(\d+)\)/i);
                var hex = color.match(/^#([0-9a-f]{3}|[0-9a-f]{6})$/i);
                var r, g, b;

        document.addEventListener('DOMContentLoaded', function() {
            // Fix empty headings - remove from DOM so axe cannot flag them
            document.querySelectorAll('h1, h2, h3, h4, h5, h6').forEach(function(heading) {
                if (heading.textContent.trim() === '') {
                    var hasImg = false;
                    heading.querySelectorAll('img').forEach(function(img) {
                        if (img.alt && img.alt.trim() !== '') hasImg = true;
                    });
                    if (!hasImg) {
                        heading.parentNode.removeChild(heading);
                    }
                }
            });

            // Fix target="_blank" accessibility warning
            document.querySelectorAll('a[target="_blank"]').forEach(function(link) {
                if (!link.title || !link.title.toLowerCase().includes('nova janela')) {
                    link.setAttribute('title', 'Abre em nova janela');
                }
                if (link.hasAttribute('aria-label')) {
                    var label = link.getAttribute('aria-label');
                    if (!label.toLowerCase().includes('nova janela')) {
                        link.setAttribute('aria-label', label + ' (Abre em nova janela)');
                    }
                } else if (!link.innerText.includes('Abre em nova janela')) {
                    var span = document.createElement('span');
                    span.className = 'visually-hidden';
                    span.innerText = ' (Abre em nova janela)';
                    link.appendChild(span);
                }
            });

            // Fallback for image redundant alt
            document.querySelectorAll('a').forEach(function(link) {
                const img = link.querySelector('img');
                if (img && typeof img.alt === 'string' && typeof link.innerText === 'string' && img.alt !== '') {
                    if (link.innerText.trim() !== '' && img.alt.trim().toLowerCase() === link.innerText.trim().toLowerCase()) {
                        img.alt = '';
                    }
                }
            });
            // Layout tables fallback (missing TH)
            document.querySelectorAll('table').forEach(function(table) {
                if (!table.querySelector('th')) {
                    table.setAttribute('role', 'presentation');
                }
            });

            // Fix skipped heading levels by replacing DOM elements
            var lastLevel = 0;
            document.querySelectorAll('h1, h2, h3, h4, h5, h6').forEach(function(heading) {
                if (heading.getAttribute('aria-hidden') === 'true') return;
                var currentLevel = parseInt(heading.tagName.substring(1));
                if (lastLevel > 0 && currentLevel > lastLevel + 1) {
                    var newLevel = lastLevel + 1;
                    var newTag = document.createElement('h' + newLevel);
                    for (var i = 0; i < heading.attributes.length; i++) {
                        newTag.setAttribute(heading.attributes[i].name, heading.attributes[i].value);
                    }
                    newTag.innerHTML = heading.innerHTML;
                    heading.parentNode.replaceChild(newTag, heading);
                    lastLevel = newLevel;
                } else {
                    lastLevel = currentLevel;
                }
            });

            // Fix generic link text (Leia mais, clique aqui)
            document.querySelectorAll('a').forEach(function(link) {
                var text = link.innerText.trim().toLowerCase();
                var genericTexts = ['leia mais', 'veja mais', 'clique aqui', 'more', 'saiba mais', 'ver mais', 'acesse', 'acessar'];
                if (genericTexts.includes(text) && !link.hasAttribute('aria-label')) {
                    var context = link.closest('article, .card, .noticia, .tab-pane');
                    var heading = context ? context.querySelector('h1, h2, h3, h4, h5, h6') : null;
                    if (heading) {
                        link.setAttribute('aria-label', link.innerText + ' sobre ' + heading.innerText);
                    } else {
                        link.setAttribute('aria-label', link.innerText + ' - ' + document.title);
                    }
                }
            });
        });
