                    <div class="fs-6"><h1>Sobre</h1>
<p>A API de Dados Abertos da Assembleia Legislativa de Minas Gerais é uma <strong>interface de acesso livre</strong> que permite a reutilização, em <strong>aplicações digitais</strong>, de informações publicadas no <a href="https://www.almg.gov.br/" title="Acessar Portal da ALMG">Portal da ALMG</a>. Em geral, essas aplicações são desenvolvidas por entidades da sociedade civil, &nbsp;em busca de cruzamentos de dados para análises detalhadas sobre a instituição avaliada.</p>
<p>A API da ALMG oferece dados estruturados, facilitando a criação de aplicações e a <strong>análise de informações </strong>relacionadas aos parlamentares, ao processo legislativo e ao orçamento da instituição.&nbsp;</p>
<h3><strong>Número de requisições&nbsp;</strong></h3>
<p>As requisições ao serviço de Dados Abertos são limitadas para evitar sobrecarga no sistema. Elas devem seguir as seguintes recomendações:</p>
<ul>
<li><strong>Requisições simultâneas:</strong> somente podem ser requisitadas, ao mesmo tempo, duas informações. Caso este limite seja extrapolado será exibida mensagem de acesso negado</li>
<li><strong>Intervalo entre requisições:</strong> o intervalo de término de uma requisição e início de outra deve ser de, no mínimo, um segundo</li>
</ul>
<p>O acesso ao serviço poderá ser bloqueado sem aviso prévio no caso do não cumprimento das recomendações citadas acima.</p>
<h3>Sobre a API</h3>
<p>Ao usar a API disponível neste site, o usuário expressa sua concordância com as seguintes condições:</p>
<ul>
<li>A Assembleia se reserva o direito de modificar, suspender ou descontinuar qualquer aspecto da API disponibilizada, a seu exclusivo critério, sem responsabilidade por eventuais intercorrências geradas dessas implementações</li>
<li>A Assembleia não presta suporte ao usuário, salvo em caso excepcionais, a seu exclusivo critério e podendo interrompê-lo a qualquer momento, sem aviso prévio</li>
<li>O usuário dos Dados Abertos da Assembleia se responsabiliza integralmente pelo uso que deles fizer</li>
<li>A Assembleia se reserva o direito de atualizar e alterar essas regras a qualquer tempo</li>
<li>O usuário pode reportar erros técnicos e dificuldades pelo Fale com a Assembleia</li>
</ul>
<h3>Sobre os arquivos CSV</h3>
<p>Alguns arquivos CSV originados dos sistemas internos da Assembleia estão disponíveis.</p>
<h3>Termos de uso</h3>
<p>Além das condições já descritas, os <a href="https://www.almg.gov.br/portal-da-almg/termos-de-uso-e-politica-de-privacidade/" title="Termos de Uso e Política de Privacidade do Portal ALMG">Termos de Uso e Política de Privacidade</a> do Portal ALMG se aplicam a este serviço.&nbsp;&nbsp;</p>

                <div class="h3 m-0 p-0 mb-1 ">Avisos</div>
                    <dl>
                            <dt class="text-info">Dados utilizados pelo site de monitoramento de Políticas Públicas da ALMG estão disponíveis na API de Dados Abertos</dt>
                        <dd class="small pb-3 mb-2"><p>Informações do site de <a href="https://politicaspublicas.almg.gov.br/">Políticas Públicas da ALMG</a> agora estão disponíveis para consulta pelo site de Dados Abertos. A documentação da API pode ser consultada nas categorias "Políticas Públicas - Monitoramento", "Políticas Públicas - Monitoramento por Região" e "Políticas Públicas - Tesauro". </p>
<p><br /><strong>Por que isso é importante?</strong></p>
<p>Compreender como funcionam as políticas públicas permite que mais pessoas possam participar ativamente de sua formulação e acompanhar sua execução, o que amplia a compreensão sobre a atuação governamental em Minas Gerais, fortalece a democracia e o controle social.</p>
<p><em>Data de publicação: 19/10/2026</em></p></dd>
                            <dt class="text-info">Novos arquivos CSV e endpoints para contratações (licitações), contratos, convênios e atas de registro de preço.</dt>
                        <dd class="small pb-3 mb-2"><p>Continuando a publicação de dados da ALMG, foram disponibilizados novos arquivos CSV e <em>endpoints </em>para contratações (licitações), contratos, convênios e atas de registro de preço. Os dados são provenientes de sistemas internos da ALMG, dados do Portal de Compras de Minas Gerais e do Portal Nacional de Contratações Públicas. Os dados disponibilizados no formato CSV também podem ser filtrados e consultados na própria tela deste site.</p>
<p><em>Endpoints:<br /></em><a href="https://dadosabertos.almg.gov.br/api/ajuda/swagger/view/lastest#/paths/api-v2-contratacoes-pesquisa/get">https://dadosabertos.almg.gov.br/api/ajuda/swagger/view/lastest#/paths/api-v2-contratacoes-pesquisa/get</a><br /><a href="https://dadosabertos.almg.gov.br/api/ajuda/swagger/view/lastest#/paths/api-v2-contratos-pesquisa-contratos/get">https://dadosabertos.almg.gov.br/api/ajuda/swagger/view/lastest#/paths/api-v2-contratos-pesquisa-contratos/get</a><br /><a href="https://dadosabertos.almg.gov.br/api/ajuda/swagger/view/lastest#/paths/api-v2-contratos-pesquisa-convenios/get">https://dadosabertos.almg.gov.br/api/ajuda/swagger/view/lastest#/paths/api-v2-contratos-pesquisa-convenios/get</a><br /><a href="https://dadosabertos.almg.gov.br/api/ajuda/swagger/view/lastest#/paths/api-v2-contratos-pesquisa-atas/get">https://dadosabertos.almg.gov.br/api/ajuda/swagger/view/lastest#/paths/api-v2-contratos-pesquisa-atas/get</a><br /><br />Novos arquivos no formato CSV:<br /><a href="https://dadosabertos.almg.gov.br/documentacao/arquivos/atas-de-registro-de-precos">https://dadosabertos.almg.gov.br/documentacao/arquivos/atas-de-registro-de-precos</a><br /><a href="https://dadosabertos.almg.gov.br/documentacao/arquivos/atas-de-registro-de-precos">https://dadosabertos.almg.gov.br/documentacao/arquivos/contratos</a><br /><a href="https://dadosabertos.almg.gov.br/documentacao/arquivos/atas-de-registro-de-precos">https://dadosabertos.almg.gov.br/documentacao/arquivos/convenios</a><br /><a href="https://dadosabertos.almg.gov.br/documentacao/arquivos/atas-de-registro-de-precos">https://dadosabertos.almg.gov.br/documentacao/arquivos/contratacoes</a></p>
<p><em>Data de publicação: 28/04/2026</em></p></dd>
                            <dt class="text-info">Novos campos para reunião e resultado de reunião de comissão e histórico de membro de comissão</dt>
                        <dd class="small pb-3 mb-2"><p>Reunião e resultado de reunião de comissão agora retornam as proposições em debate (campo proposicoesEmDebate). O histórico de membros de comissão (MembroHistoricoComissao) tem agora os campos para a data de início e término da participação do deputado na comissão, tanto para o titular, quanto para o suplente. </p>
<p>Exemplos: <br /><a href="https://dadosabertos.almg.gov.br/api/v2/comissoes/1/reunioes/2/2013/04/11/09:30">https://dadosabertos.almg.gov.br/api/v2/comissoes/1/reunioes/2/2013/04/11/09:30</a></p>

<p><em>Data de publicação: 28/04/2026</em></p></dd>
                            <dt class="text-info">Novos campos para o CSV de Legislação Mineira</dt>
                        <dd class="small pb-3 mb-2"><p>Foram incluídos os campos Situacao, NormaBasica e Indexacao ao arquivo CSV para a Legislação Mineira. Para mais informações, consulte a documentação em <a title="Legislação Mineira" href="https://dadosabertos.almg.gov.br/documentacao/arquivos/legislacao-mineira">Legislação Mineira</a>. </p>
<p><em>Data de publicação: 17/03/2026</em></p></dd>
                            <dt class="text-info">Versão antiga da API descontinuada</dt>
                        <dd class="small pb-3 mb-2"><p>A versão antiga da API foi <strong>descontinuada</strong>.                             <dt class="text-info">Teste a nova versão da API</dt>
                        <dd class="small pb-3 mb-2"><p>A versão antiga da API (<a href="https://dadosabertos.almg.gov.br/ws/ajuda/sobre" title="Acessar ajuda da versão obsoleta">consulte documentação</a>) será <strong>descontinuada</strong> após<strong> 5/6/25</strong>. Em geral, a nova versão deste site traz chamadas e formatos de resposta <strong>compatíveis</strong> com a versão anterior.</p>
<p>Todos os <em>endpoints</em> (inclusive parâmetros - <em>queryparams - </em> e resultados), e suas categorias, foram preservados. Ex: <br />Nova versão - <a target="_blank" href="https://dadosabertosn.almg.gov.br/api/v2/pronunciamentos/tipos" style="word-break: break-all;" rel="noopener">https://dadosabertos.almg.gov.br/api/v2/pronunciamentos/tipos</a>.<br />Versão anterior -<a target="_blank" href="https://dadosabertos.almg.gov.br/ws/pronunciamentos/tipos" rel="noopener" style="word-break: break-all;">https://dadosabertos.almg.gov.br/ws/pronunciamentos/tipos</a>.</p>
<p>Como há pequenas diferenças<strong> </strong>no formato do XML ou do JSon retornado, é importante <strong>testar</strong> a nova versão. A regra geral é trocar  <code>"/ws"</code> para <code>"/api/v2"</code>  no link do <em>endpoint</em> utilizado. </p>

            // Function to toggle dropdown
            function toggleDropdown(dropdown) {
                const dropdownMenu = dropdown.querySelector('.dropdown-menu');
                dropdownMenu.classList.toggle('show');
            }

            // Close dropdowns when clicking outside
            document.addEventListener('click', function(event) {
                const dropdowns = document.querySelectorAll('.dropdown');
                dropdowns.forEach(function(dropdown) {
                    if (!dropdown.contains(event.target)) {
                        const dd = dropdown.querySelector('.dropdown-menu');
                        if (dd){
                            dd.classList.remove('show');
                        }
                    }
                });
            });

            // Prevent dropdown from closing when clicking inside it
            document.addEventListener('click', function(event) {
                if (event.target.matches('.dropdown-menu') || event.target.closest('.dropdown-menu')) {
                    event.stopPropagation();
                }
            });

            // Add click event listeners to dropdown toggles
            document.addEventListener('DOMContentLoaded', function() {
                const dropdownToggles = document.querySelectorAll('.dropdown-toggle');
                dropdownToggles.forEach(function(toggle) {
                    toggle.addEventListener('click', function(event) {
                        event.preventDefault();
                        const dropdown = this.closest('.dropdown');
                        toggleDropdown(dropdown);
                    });
                });
            });
        </script>

                 function getCurrentServerURL() {
                   // Get the current protocol (http or https)
                   const protocol = window.location.protocol;

                   // Get the hostname (server name)
                   const hostname = window.location.hostname;

                   // Get the port number (if applicable)
                   const port = window.location.port;

                   // Construct the URL string
                   let url = protocol + '//' + hostname;

                   // Append the port if it's non-standard (not 80 for http or 443 for https)
                   if (port && port !== '80' && port !== '443') {
                     url += ':' + port;
                   }

                   return url + '/';
                 }

                            anchor.href.startsWith('http://dados-abertos/')
                        );

                        // Remove the prefix from relevant hrefs
                        relevantAnchors.forEach(anchor => {
                            anchor.href = anchor.href.replace('http://dados-abertos/', getCurrentServerURL());
